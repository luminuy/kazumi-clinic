# คู่มือแปลไทย → อังกฤษ — Kazumi Clinic

เอกสารนี้คือ **สัญญาการแปล** ของเว็บนี้ ใช้กับทั้งคน เครื่องมือแปล และ LLM (Gemini CLI ฯลฯ)
ทุกก้อนที่แปลต้องผ่านกฎในหน้านี้ก่อนเข้า `messages/en.json`, ฟิลด์ `*En` ใน `lib/services.ts`
หรือคอลัมน์ `*_en` ใน D1

> โครงสร้าง i18n (locale, path, การเพิ่ม key) อยู่ที่ [CLAUDE.md §13](../CLAUDE.md) — หน้านี้พูดเรื่อง **ถ้อยคำ** อย่างเดียว

ตรวจงานแปลด้วย:

```bash
pnpm i18n:check
```

## 🔴 กฎที่ผิดแล้วผิดกฎหมาย ไม่ใช่แค่ผิดสำนวน

คลินิกอยู่ใต้ พ.ร.บ.สถานพยาบาล และประกาศ อย./สบส. เรื่องโฆษณา ([CLAUDE.md §0.2](../CLAUDE.md))
**ภาษาอังกฤษต้องอ้างไม่เกินภาษาไทย** — ห้ามให้คำแปล "ขายดีกว่า" ต้นฉบับ

| ห้ามโผล่ในคำแปล | เพราะ |
| --- | --- |
| `guarantee`, `guaranteed results`, `100% safe`, `no side effects` | รับประกันผลลัพธ์ = โฆษณาเกินจริง |
| `permanent`, `forever`, `cure`, `heals` | อ้างสรรพคุณเกินจริง (ยกเว้นต้นฉบับไทยพูดแบบนั้นจริง ซึ่งถ้าเจอ ให้ทักกลับ อย่าแปลตาม) |
| `best`, `#1`, `world-class`, `miracle` | คำโอ้อวดที่ไทยไม่ได้เขียนไว้ |
| เติมสรรพคุณที่ต้นฉบับไม่มี | คำแปลต้อง**ไม่เพิ่มข้อมูล** |

LLM มีนิสัยเติมคำโฆษณาให้เอง — ทุกก้อนที่แปลด้วยเครื่องต้อง diff ความหมายกับไทยก่อน merge
และเนื้อหาการตลาด/การแพทย์ใหม่ต้องให้เจ้าของคลินิก/แพทย์อ่านผ่าน **ก่อน merge** (merge = ขึ้นเว็บทันทีเพราะมี CD)

## โทนเสียง

- **สุภาพ ชัดเจน ไม่ขายของ** — โทนเดียวกับไทย: ให้ข้อมูล ไม่เร่งเร้า
- เขียนแบบ **British/International English** ที่เป็นกลาง (`personalised` หรือ `personalized` เลือกอย่างใดอย่างหนึ่งให้ทั้งเว็บ — ปัจจุบันไซต์ใช้ **-ize**)
- ประโยคสั้น ไม่ยัดสามอนุประโยคในหนึ่งประโยค
- **ห้ามแปลตรงตัวจนอ่านแล้วรู้ว่าแปลมา** เช่น
  - ❌ `assessed and cared for by doctors at every step` → ✅ `with a doctor involved at every step`
  - ❌ `reserve a queue via LINE` → ✅ `book via LINE`
- ปุ่ม/label ใช้ **sentence case** (`Book an appointment` ไม่ใช่ `Book An Appointment`)
- หัวข้อหมวด (`<h1>`/`<h2>`) ใช้ **Title Case**
- อังกฤษยาวกว่าไทยราว 20–40% — ข้อความในปุ่มและการ์ดต้องสั้นพอไม่ให้ layout ล้น ([docs/design.md](./design.md))

## Alt text และ metadata

- `alt` ต้องบรรยาย**สิ่งที่เห็นจริงในรูป** ไม่ใช่แปลชื่อไฟล์หรือยัด keyword
- รูปตกแต่งล้วนใช้ `alt=""` ทั้งสองภาษา
- `metaDescription` ภาษาอังกฤษ **ไม่ใช่คำแปลตรงตัวของไทย** — เขียนให้อ่านเป็นธรรมชาติในผลค้นหา ยาวไม่เกิน ~155 ตัวอักษร และห้ามเกินขอบเขตสรรพคุณตามกฎด้านบน

## ขั้นตอนเมื่อแปลด้วย Gemini CLI

1. ส่งงานเป็น **ก้อน JSON** พร้อมกฎในไฟล์นี้ใน prompt เสมอ
2. สั่งให้ **คืน JSON โครงสร้างเดิม** ไม่ใส่คำอธิบายรอบ ๆ
3. บอกให้ **ทักกลับถ้าต้นฉบับไทยกำกวมหรือขัดกับกฎ** ห้ามเดาแล้วแปลไปเลย
4. รัน `pnpm i18n:check` กับผลลัพธ์ **ทุกครั้ง** (ตรวจ placeholder, ตัวอักษรไทยตกค้าง, คำโฆษณาต้องห้าม)
5. อ่าน diff เองทีละก้อน — เครื่องมือตรวจจับ "แปลผิดความหมาย" ไม่ได้
6. เนื้อหาการตลาด/การแพทย์ → ให้เจ้าของอ่านผ่านก่อน merge
